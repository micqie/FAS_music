🔄 Clear Browser Cache

Updated: August 26, 2026 - Version 20260826001

⚠️ Why clear cache?
The JavaScript files have been updated with important fixes:
  • ✅ Fixed instrument dropdown default to "Select..." instead of "Bass Guitar"
  • ✅ Fixed instrument validation to properly detect selected instruments
  • ✅ Fixed payment calculation for Full and Partial payment types
  • ✅ Added 30% deposit display for partial payments

Method 1: Hard Refresh (Quickest)

  1. Go to the enrollment page: http://localhost/FAS_music/pages/desk/desk_enrollment.html
  2. Press the keyboard shortcut for your browser:
    • Windows (Chrome/Edge/Firefox): Ctrl + Shift + R or Ctrl + F5
    • Windows (Chrome/Edge): Shift + F5
  3. Wait for the page to fully reload

Method 2: Clear All Cached Data

Google Chrome / Microsoft Edge:

  1. Press Ctrl + Shift + Delete
  2. Select "All time" from the Time range dropdown
  3. Check "Cached images and files"
  4. Click "Clear data"
  5. Refresh the page with F5

Mozilla Firefox:

  1. Press Ctrl + Shift + Delete
  2. Select "Everything" from the Time range dropdown
  3. Check "Cache"
  4. Click "Clear Now"
  5. Refresh the page with F5

Method 3: Open Developer Tools

  1. Press F12 to open Developer Tools
  2. Right-click the refresh button in your browser
  3. Select "Empty Cache and Hard Reload"
✅ How to verify the cache is cleared:
  1. Open the enrollment page
  2. Open the Walk-In Enrollment modal
  3. Select a student
  4. Check that the instrument dropdown shows "Select..." as the first option
  5. Press F12 and check the Console tab for debug logs starting with [getResolvedInstrumentIds]
  6. Change the Payment Type between Full and Partial - you should see "Payable Now (30%)" for partial payments

The page now includes cache-busting parameters (?v=20260826001) on all JavaScript files. Future updates will automatically load the new versions.
